# MUSINSA Unlisted Product Check

무신사·29CM **판매중** 상품 중에서 고객에게 제대로 보이지 않는 상품을 찾는 도구입니다.
화면 맨 위 [판매채널]에서 **무신사** 또는 **29CM**를 고릅니다. 29CM는 아래 [29CM](#29cm) 참고.

1. **옵션 재고 점검** — 셀메이트에는 재고가 있는데 무신사 옵션은 품절(또는 판매 제한)이라 고를 수 없는 옵션, 컬러 묶음 상품의 일부 컬러·사이즈 품절, 무신사에 옵션 자체가 없는 경우, 스타일넘버 오입력
2. **검색 노출 점검** — 판매중 상품 전체를 크롬으로 무신사 검색창에 **"브랜드명 + 상품명"**(컬러명·`_3COL` 같은 컬러 묶음 표기 제외)을 직접 입력해 검색하고, **검색 결과 화면**에 우리 브랜드 상품으로 나오는지 확인. 안 나오면 화면 캡처

- 입력: 무신사 **재고 관리(v2)** 표 복사본 + **셀메이트 재고목록**(CSV)
- 결과: `무신사_옵션재고점검_날짜.xlsx`, `무신사_검색노출점검_날짜.xlsx`, `미노출_캡처/` 폴더

기본 브랜드는 **어반드레스**이고, 같은 무신사 스토어에 섞여 있는 젠더스트(`ZD`)·비바셔스(`VV`) 스타일넘버는 제외합니다. 화면의 [설정]에서 바꿀 수 있습니다.

## 바로 쓰기 (Windows exe)

1. GitHub → **Actions** → `Build Windows exe` → 최신 실행 → 하단 **Artifacts**의 `MusinsaChecker-windows` 다운로드 (또는 Releases의 zip)
2. 압축을 풀고 `MusinsaChecker.exe` 실행
3. 재고 관리(v2) 복사본과 셀메이트 재고목록을 고르고 **[▶ 점검 시작]**
   - 옵션 재고 점검 엑셀이 먼저 만들어지고(1분), 크롬이 열려 판매중 상품을 하나씩 검색합니다 (상품 1,000개 기준 40~60분)
   - 중간에 [■ 중지] → 나중에 [검색만 이어서 하기]
4. `무신사_옵션재고점검` → **상품별_한눈에보기**, `무신사_검색노출점검` → **검색_미노출** 시트 확인

자세한 사용법: zip 안의 `사용법.txt` ([docs/사용법.txt](docs/사용법.txt))

처음 실행할 때 Windows 보호 화면이 뜨면 "추가 정보 → 실행"을 누르세요 (서명되지 않은 exe라서 뜨는 안내입니다).

### 입력 파일 만들기

**① 무신사 재고 관리(v2) 복사본** — 파트너센터 → 상품/재고 → **재고 관리(v2)** → 상품상태 `판매중`, 출력수 `5000` → 표를 전부 드래그해 복사(Ctrl+C) → 엑셀 새 파일에 붙여넣기(Ctrl+V) → 저장

- 머리글(매장명, 업체 …) 행은 **없어도 되고**, 맨 위나 맨 아래에 있어도 됩니다.
- 화면의 18개 열 중 점검에 쓰는 14개 열만 자동으로 골라 씁니다:
  `매장명 업체 품목 브랜드 스타일넘버 상품번호 상품명 상태 옵션 옵션번호 국내출고/브랜드배송 국내출고/무신사배송 일본출고/무신사배송 총합 판매가능`
  (`상품구분`, `사용유무`, `허용판매수량`, `재입고알림요청수`는 버림)
- 5000건이 넘으면 2페이지도 이어서 붙여넣으세요.

**② 셀메이트 재고목록** — 셀메이트 → 재고목록 → 엑셀(CSV) 다운로드 (`stk_stockList_*.csv`) 그대로.
상품명 끝의 `(품절)`·`(이월)` 표시와 관계없이 **현재재고 수량이 있으면 재고 있음**으로 봅니다.

### 무신사 검색 (자동)

크롬을 이 프로그램 전용 프로필로 따로 띄워(평소 쓰는 크롬과 별개, 비로그인) 고객처럼 검색합니다.

1. 상단 [검색] 버튼 클릭 → 검색창에 `어반드레스 + 상품명` 입력 → Enter
2. 검색 결과 화면의 상품 카드를 화면을 내려가며 최대 60개까지 읽어 상품번호·브랜드명 확인 (추천 영역 '29CM' 등은 제외)
3. 그 상품이 우리 브랜드로 안 보이면 화면 캡처 → `미노출_캡처/상품번호_상품명.png`, 엑셀에 "캡처 보기" 링크

- 같은 검색어(예: 컬러별로 따로 등록된 상품)는 한 번만 검색합니다.
- 판정은 화면 기준입니다. 페이지 제목의 "총 N건"은 화면과 다를 수 있습니다 ('유니섹스' 검색어는 제목은 총 8건인데 화면은 "검색 결과가 없습니다").
- 크롬 원격 제어(DevTools Protocol)만 써서 별도 드라이버 설치가 필요 없습니다. 크롬이 없으면 엣지를 씁니다.
- 자동 검색이 안 되면 예비 버튼으로 이전 방식(크롬 F12 콘솔에 스크립트 붙여넣기)을 쓸 수 있습니다.

## 결과 엑셀

모든 시트 1행에 "왜 만들었나 / 읽는 법"이 있고, 2행이 헤더입니다.

### `무신사_옵션재고점검_날짜.xlsx` (점검 시작 1분 뒤 생성, 검색이 끝나면 검색 결과 반영)

| 시트 | 내용 |
|---|---|
| **요약** | 옵션 판정별 수, 점검 필요 상품 수, 판정 기준 |
| **상품별_한눈에보기** | 무신사 상품 1개 = 1줄, 조치가 필요한 상품만. ① 셀메이트 재고 있는 옵션 품절 / ② 다른 옵션명·상품번호로 판매중 / ③ 확인필요. **작업은 이 시트부터** |
| **무신사_검색노출** | 위 점검 필요 상품의 검색 결과 |
| **옵션별_점검** | 무신사 옵션 ↔ 셀메이트 옵션 1:1 대조 전체 |
| **무신사에_옵션없음** | 셀메이트 재고가 있는데 무신사 상품에 그 옵션 자체가 없음 |
| **상품명_대조** | 스타일넘버 오입력 의심 등 확인이 필요한 상품 |

판정 기준: 브랜드배송 0 + 무신사배송(MFS) 재고가 있으면 정상, 같은 셀메이트 옵션이 같은 상품 안 다른 옵션명이나 다른 상품번호로 판매중이면 우선순위 낮음, 젠더스트(ZD)·비바셔스(VV)와 세트 상품 제외.

### `무신사_검색노출점검_날짜.xlsx` (검색이 끝나면 완성)

| 시트 | 내용 |
|---|---|
| **요약** | 검색됨 / 검색 안 됨 / 미확인 상품 수, 검색 안 됨 원인별 수 |
| **검색_미노출** | 판매중인데 검색 결과 화면에 안 나오는 상품만, "캡처 보기" 링크. **작업은 이 시트부터** |
| **전체_검색결과** | 판매중 상품 전체. 검색어, 검색 결과 수, 화면 순위, 옵션 수, 판매가능 재고, 검색·상품 링크 |

`비고`에 적는 원인

| 비고 | 뜻 |
|---|---|
| 검색어에 '유니섹스'가 들어가면 결과 화면이 비어 보임 | 무신사 웹 검색 현상(사이트 전체). '유니섹스'를 빼면 노출됨 → 상품명 수정 검토 |
| 판매가능 재고 0 (전 옵션 품절) | 모든 옵션이 품절이라 검색에서 빠졌을 수 있음 |
| 검색 결과 0건 | 상품명·검색 키워드 확인 필요 |
| 검색 결과에 다른 상품만 나옴 | 무신사에서 상품 전시 상태 확인 필요 |

## 설정

화면의 **[설정(브랜드명)]** → `settings.json`

| 항목 | 설명 |
|---|---|
| `BRAND_KR` | 무신사에 표시되는 브랜드명. 검색어 앞에 붙고, 검색 결과의 브랜드를 이 이름으로 확인 |
| `EXCLUDE_CODE_PATTERN` | 점검에서 뺄 스타일넘버 정규식 (기본 `^(ZD|VV)`) |

## 폴더 구조

```
├─ app/
│  ├─ gui.py                 # exe 실행 화면 (tkinter) — 점검 시작 / 중지 / 이어서 검색
│  └─ runner.py              # prepare() / auto_search() / apply_search() — 화면·명령줄 공용
├─ src/
│  ├─ search_check.py        # 재고 관리(v2) 복사본 읽기, 상품명 정리, 검색 노출 엑셀
│  ├─ ui_search.py           # 크롬을 띄워 무신사 검색창에 직접 검색, 미노출 화면 캡처
│  ├─ step2_name_check.py    # 상품명·스타일넘버 대조
│  ├─ step3_option_match.py  # 무신사 옵션 ↔ 셀메이트 옵션 매칭
│  ├─ step4_option_judge.py  # 옵션 판정 (품절·판매 제한·MFS 등)
│  └─ step6_option_report.py # 옵션 재고 점검 엑셀
├─ search/
│  └─ musinsa_brand_search.js# (예비) 크롬 콘솔용 검색 스크립트
├─ config.py                 # 브랜드명·제외 규칙·수동 연결 (settings.json으로 덮어씀)
├─ musinsa_checker.spec      # PyInstaller 설정
├─ .github/workflows/build-exe.yml  # Windows exe 자동 빌드 + 가짜 데이터로 자체 점검
└─ tests/
   ├─ make_fixture.py        # 시험용 가짜 입력 파일 생성
   ├─ mock_musinsa.py        # 시험용 가짜 무신사 검색 화면 (로컬 서버)
   └─ mock_29cm.py           # 시험용 가짜 29CM 검색 화면 (로컬 서버)
```

명령줄로 실행: `python app/runner.py <재고관리_복사본.xlsx> <셀메이트_재고목록.csv> [결과폴더] [--auto | 검색결과.txt]`

### exe 빌드

`main`에 `app/`, `src/`, `search/`, `tests/`, `config.py`, `musinsa_checker.spec`이 바뀌어 push되면 GitHub Actions가 Windows에서 PyInstaller로 빌드하고, 가짜 데이터와 가짜 무신사 검색 화면으로 exe 자체 점검(`--selftest`, 크롬 자동 검색 포함)을 돌린 뒤 zip을 올립니다. 직접 빌드하려면 Windows에서 `pip install -r requirements.txt pyinstaller` 후 `pyinstaller musinsa_checker.spec`.

## 29CM

- 입력: **29CM 옵션재고 일괄변경(파트너) 파일 여러 개**(29Connect에서 판매중 상품을 페이지마다 다운로드한 `29CM_옵션재고_일괄변경(파트너)_페이지…xlsx`) + 셀메이트 재고목록
- 29CM 파일에는 셀메이트 상품코드가 없어 **상품명으로 매칭**합니다: 컬러 묶음 표기(`- 3COL`, `_3Colors`, `7 COLOR`)·끝 컬러명 제거 →
  같은 이름 / 셀메이트 이름 = 29CM 이름 + 컬러 / 단어 포함 / 비슷한 이름 / 한글↔영문(의류 용어 사전 + 발음 비교). 세트(`[SET] A + B`)는 구성품별.
  옵션은 `[색상]`·`[사이즈]` 꼬리표를 떼고 컬러·사이즈로 1:1 대조 (한글 컬러 → 영문, (기모)·(쭈리) 구분 유지)
- 검색: 크롬으로 29CM 검색창에 "브랜드명 + 상품명" 입력 → 검색 결과 카드의 상품번호(`catalog/번호`)·브랜드 링크 확인 (비로그인, 추천순 첫 페이지 최대 50개)

| 결과 | 시트 |
|---|---|
| `29CM_옵션재고점검_날짜.xlsx` | **요약**, **상품별_한눈에보기**(조치 필요 상품, 검색 후 "29CM 검색" 열), **옵션별_대조**, **29CM에_옵션없음**, **상품매칭_확인필요** |
| `29CM_검색노출점검_날짜.xlsx` | **요약**, **검색_미노출**("캡처 보기"/"검색 열기"), **전체_검색결과** |
| `29CM_미노출_캡처/` | 검색 안 된 상품의 검색 화면 |

명령줄: `python app/runner.py --29cm "<29CM파일1.xlsx;29CM파일2.xlsx>" <셀메이트_재고목록.csv> [결과폴더] [--auto]`

## 등록 현황 점검 (명령줄 전용, exe에는 없음)

셀메이트 상품 중 무신사 **미등록·판매중지** 상품 찾기는 `src/step1_*.py`와 `run_all.py --listing`에 남아 있습니다. 무신사 상품정보조회(전체 상태) 파일이 필요합니다.

## 주의사항

- **입력·결과 파일은 레포에 올리지 마세요.** `data/`, `output/`, `*.xlsx`, `*.csv`는 `.gitignore`에 들어 있습니다.
- 검색 스크립트는 무신사 검색 결과 페이지의 내부 데이터를 읽습니다. 무신사 사이트 구조가 바뀌면 동작하지 않을 수 있습니다.
- 확인 범위는 **비로그인 웹 검색(전체 성별), 결과 첫 페이지(최대 60개)** 입니다. 앱·카테고리·브랜드관 노출은 확인하지 않습니다.
- 검색 결과는 시점마다 달라질 수 있습니다.

버전별 변경 내용은 [CHANGELOG.md](CHANGELOG.md)에 있습니다.
