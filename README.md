# MUSINSA Unlisted Product Check

**무신사에 판매중인데, 고객이 상품명으로 검색했을 때 검색 결과에 안 나오는 상품**을 찾는 도구입니다.

- 입력: 무신사 파트너센터 **재고 관리(v2)** 표를 그대로 복사해 엑셀로 저장한 파일 하나
- 검색: 상품마다 **"브랜드명 + 상품명"**(컬러명·`_3COL` 같은 컬러 묶음 표기 제외)으로 무신사를 검색
- 판정: **실제 검색 결과 화면**에 그 상품번호가 우리 브랜드로 나오면 `검색됨`, 아니면 `검색 안 됨` + 원인
- 결과: `무신사_검색노출점검_날짜.xlsx` (검색_미노출 / 전체_검색결과 / 요약)

기본 브랜드는 **어반드레스**이고, 같은 무신사 스토어에 섞여 있는 젠더스트(`ZD`)·비바셔스(`VV`) 스타일넘버는 제외합니다. 화면의 [설정]에서 바꿀 수 있습니다.

---

## 바로 쓰기 (Windows exe)

1. GitHub → **Actions** → `Build Windows exe` → 최신 실행 → 하단 **Artifacts**의 `MusinsaChecker-windows` 다운로드 (또는 Releases의 zip)
2. 압축을 풀고 `MusinsaChecker.exe` 실행
3. 재고 관리(v2) 복사본을 고르고 **① → ② → ③** 순서로 누르기
4. 결과 엑셀의 **검색_미노출** 시트 확인

자세한 사용법: zip 안의 `사용법.txt` ([docs/사용법.txt](docs/사용법.txt))

처음 실행할 때 Windows 보호 화면이 뜨면 "추가 정보 → 실행"을 누르세요 (서명되지 않은 exe라서 뜨는 안내입니다).

### 입력 파일 만들기

파트너센터 → 상품/재고 → **재고 관리(v2)** → 상품상태 `판매중`, 출력수 `5000` → 표를 전부 드래그해 복사(Ctrl+C) → 엑셀 새 파일에 붙여넣기(Ctrl+V) → 저장

- 머리글(매장명, 업체 …) 행은 **없어도 되고**, 맨 위나 맨 아래에 있어도 됩니다.
- 화면의 18개 열 중 점검에 쓰는 14개 열만 자동으로 골라 씁니다:
  `매장명 업체 품목 브랜드 스타일넘버 상품번호 상품명 상태 옵션 옵션번호 국내출고/브랜드배송 국내출고/무신사배송 일본출고/무신사배송 총합 판매가능`
  (`상품구분`, `사용유무`, `허용판매수량`, `재입고알림요청수`는 버림)
- 5000건이 넘으면 2페이지도 이어서 붙여넣으세요.

### 무신사 검색 (② 단계)

무신사는 프로그램의 직접 접속을 막을 수 있어서, 검색은 **본인 크롬**에서 합니다. 로그인은 필요 없습니다.

1. ② 버튼 → 검색 스크립트가 복사되고 무신사가 열림
2. F12 → **Console** 탭 → Ctrl+V → Enter (처음이면 `allow pasting` 입력 후 Enter, 다시 Ctrl+V)
3. 상품 1,000개 기준 약 10분. 끝나면 `완료`가 뜨고 결과가 클립보드에 복사됨
4. ③ 버튼 → 결과 엑셀 완성

스크립트는 무신사 검색 결과 페이지(`www.musinsa.com/search/goods`)를 불러와, 화면에 표시되는 상품 목록에서 상품번호·브랜드명을 확인합니다. (검색 API 결과와 화면이 다를 수 있어 화면 기준으로 봅니다.)

## 결과 엑셀

모든 시트 1행에 "왜 만들었나 / 읽는 법"이 있고, 2행이 헤더입니다.

| 시트 | 내용 |
|---|---|
| **요약** | 검색됨 / 검색 안 됨 / 미확인 상품 수, 검색 안 됨 원인별 수 |
| **검색_미노출** | 판매중인데 검색 결과 화면에 안 나오는 상품만. **작업은 이 시트부터** |
| **전체_검색결과** | 판매중 상품 전체. 검색어, 검색 결과 수, 화면 순위, 옵션 수, 판매가능 재고, 검색·상품 링크 |

`비고`에 적는 원인

| 비고 | 뜻 |
|---|---|
| 검색어에 '유니섹스'가 들어가면 결과 화면이 비어 보임 | 무신사 웹 검색 현상(사이트 전체). '유니섹스'를 빼면 노출됨 → 상품명 수정 검토 |
| 판매가능 재고 0 (전 옵션 품절) | 모든 옵션이 품절이라 검색에서 빠졌을 수 있음 |
| 검색 결과 0건 | 상품명·검색 키워드 확인 필요 |
| 검색 결과에 다른 상품만 나옴 | 무신사에서 상품 전시 상태 확인 필요 |

## 설정

화면의 **[설정(브랜드명)]** → `settings.json`

| 항목 | 설명 |
|---|---|
| `BRAND_KR` | 무신사에 표시되는 브랜드명. 검색어 앞에 붙고, 검색 결과의 브랜드를 이 이름으로 확인 |
| `EXCLUDE_CODE_PATTERN` | 점검에서 뺄 스타일넘버 정규식 (기본 `^(ZD|VV)`) |

## 폴더 구조

```
├─ app/
│  ├─ gui.py                 # exe 실행 화면 (tkinter) — ① 상품 목록 ② 검색 스크립트 ③ 결과 붙여넣기
│  └─ runner.py              # prepare() / apply_search() — 화면·명령줄 공용
├─ src/
│  └─ search_check.py        # 재고 관리(v2) 복사본 읽기, 상품명 정리, 결과 엑셀
├─ search/
│  └─ musinsa_brand_search.js# 무신사 검색 결과 화면 확인 스크립트 (크롬 콘솔)
├─ config.py                 # 브랜드명·제외 규칙 (settings.json으로 덮어씀)
├─ musinsa_checker.spec      # PyInstaller 설정
├─ .github/workflows/build-exe.yml  # Windows exe 자동 빌드 + 가짜 데이터로 자체 점검
└─ tests/make_fixture.py     # 시험용 가짜 입력 파일 생성
```

명령줄로 실행: `python app/runner.py <재고관리_복사본.xlsx> [결과폴더] [검색결과.txt]`

### exe 빌드

`main`에 `app/`, `src/`, `search/`, `tests/`, `config.py`, `musinsa_checker.spec`이 바뀌어 push되면 GitHub Actions가 Windows에서 PyInstaller로 빌드하고, 가짜 데이터로 exe 자체 점검(`--selftest`)을 돌린 뒤 zip을 올립니다. 직접 빌드하려면 Windows에서 `pip install -r requirements.txt pyinstaller` 후 `pyinstaller musinsa_checker.spec`.

## 이전 기능 (명령줄 전용, exe에는 없음)

v1~v13에서 만든 **셀메이트 재고 대조**(옵션 품절·판매 제한·MFS, 미등록·판매중지, 스타일넘버 오입력)는 `src/step*.py`와 `run_all.py`에 남아 있습니다. 셀메이트 재고목록·상품정보조회 파일이 필요하며, 사용법은 [CHANGELOG.md](CHANGELOG.md)와 `config.py` 주석을 참고하세요.

## 주의사항

- **입력·결과 파일은 레포에 올리지 마세요.** `data/`, `output/`, `*.xlsx`, `*.csv`는 `.gitignore`에 들어 있습니다.
- 검색 스크립트는 무신사 검색 결과 페이지의 내부 데이터를 읽습니다. 무신사 사이트 구조가 바뀌면 동작하지 않을 수 있습니다.
- 확인 범위는 **비로그인 웹 검색(전체 성별), 결과 첫 페이지(최대 60개)** 입니다. 앱·카테고리·브랜드관 노출은 확인하지 않습니다.
- 검색 결과는 시점마다 달라질 수 있습니다.

버전별 변경 내용은 [CHANGELOG.md](CHANGELOG.md)에 있습니다.
