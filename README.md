# MUSINSA Unlisted Product Check

셀메이트(Sellmate) 재고 목록과 무신사 파트너센터 데이터를 대조해서 아래를 찾아주는 도구입니다.

- **무신사에 등록이 안 됐거나 판매중지·품절로 묶인 상품** (셀메이트에는 재고가 있는데)
- **판매중인데 일부 옵션(컬러·사이즈)만 품절**된 상품 — `_7COL` 같은 컬러 묶음 상품 포함
- **무신사 스타일넘버가 잘못 입력된 상품** (상품명으로 교차 확인)
- **무신사 검색에서 브랜드 상품으로 노출되는지** ("어반드레스 + 상품명" 검색)

대상 브랜드는 `config.py`에서 정합니다. 기본값은 **어반드레스**(상품코드 `AD`·`AV`, 구코드 `yySS/FW+AD`)이고, 같은 무신사 스토어에 섞여 있는 젠더스트(`ZD`)·비바셔스(`VV`)는 제외합니다.

## 폴더 구조

```
├─ config.py                 # 입력 파일 경로, 브랜드 코드 규칙, 사람이 확인한 수동 연결
├─ run_all.py                # 전체 실행
├─ src/
│  ├─ load_data.py           # 셀메이트 CSV / 무신사 전체 상품 엑셀 읽기
│  ├─ step1_listing_match.py # 1. 셀메이트 상품(컬러) ↔ 무신사 상품 매칭
│  ├─ step1_listing_report.py#    → 등록 현황 엑셀
│  ├─ step2_name_check.py    # 2. 상품명 대조 (컬러·COL 표기 제외)
│  ├─ step3_option_match.py  # 3. 무신사 옵션 ↔ 셀메이트 옵션 1:1 매칭
│  ├─ step4_option_judge.py  # 4. 옵션별 판정
│  ├─ step5_search_keywords.py # 무신사 검색어 + 브라우저 검색 스크립트 생성
│  └─ step6_option_report.py # 옵션 재고 점검 엑셀
├─ search/
│  └─ musinsa_brand_search.js# 무신사 검색 노출 확인 (Chrome 콘솔에서 실행)
├─ data/                     # 입력 파일 (git 제외)
└─ output/                   # 결과 엑셀 (git 제외)
```

> **데이터는 레포에 올라가지 않습니다.** `data/`, `output/`, `*.xlsx`, `*.csv`는 `.gitignore`에 들어 있습니다. 재고·원가가 들어 있는 파일이니 레포에 직접 올리지 마세요.

`data/` 폴더에 아래 이름으로 넣어주세요. (이름을 바꾸고 싶으면 `config.py` 수정)

| 파일명 | 어디서 받나 | 비고 |
|---|---|---|
| `sellmate_stock.csv` | 셀메이트 → 재고 목록 엑셀 다운로드 (`stk_stockList_*.csv`) | 필수. cp949 인코딩 그대로 |
| `musinsa_products_all.xlsx` | 무신사 파트너센터 → 상품정보조회 → 상품상태 **전체** → 엑셀 다운로드 | 필수. 품절·판매중지·삭제 상태 확인용 |
| `musinsa_products_selling.xlsx` | 같은 화면, 상품상태 **판매중** → 엑셀 다운로드 | 옵션 점검 시 필수 |
| `musinsa_option_stock.xlsx` | 무신사 파트너센터 → 상품/재고 → **재고 관리(v2)** → 상품상태 판매중, 출력수 5000 → 표 전체 복사 → 엑셀에 붙여넣어 저장 | 옵션 점검 시 필수. 엑셀 다운로드 버튼이 없어 복사로 만듭니다. 5000건이 넘으면 2페이지도 이어 붙이기 |
| `search_brand.txt` | 아래 "무신사 검색 노출 확인" 결과 | 선택 |

재고 관리(v2) 복사본은 첫 줄이 `매장명, 업체, 품목, 브랜드, 스타일넘버, 상품번호, 상품명, 상태, 옵션, 옵션번호, 국내출고/브랜드배송, 국내출고/무신사배송, 일본출고/무신사배송, 총합 판매가능` 헤더여야 합니다.

## 실행 방법

```bash
pip install -r requirements.txt
python run_all.py              # 전체 (등록 현황 + 옵션 재고 점검)
python run_all.py --listing    # 등록 현황만 (musinsa_products_all.xlsx + 셀메이트만 있으면 됨)
```

결과는 `output/`에 생깁니다.

- `무신사_어반드레스_등록점검_YYYYMMDD.xlsx` — 셀메이트 상품(컬러) 단위 무신사 등록 현황
- `무신사_옵션재고점검_YYYYMMDD.xlsx` — 옵션 재고 점검 (메인 결과)
- `musinsa_brand_search_ready.js` — 검색 노출 확인용 스크립트 (검색어 포함)

### 무신사 검색 노출 확인 (선택)

무신사는 서버에서 자동 접속을 막아서, 검색은 **본인 Chrome**에서 합니다. 로그인은 필요 없습니다.

1. `python run_all.py` 실행 → `output/musinsa_brand_search_ready.js` 생성
2. Chrome에서 https://www.musinsa.com 접속 → `F12` → **Console** 탭
3. `musinsa_brand_search_ready.js` 내용을 전부 붙여넣고 `Enter` (상품 250개 기준 2~3분)
4. 완료되면 결과가 클립보드에 복사됨 → `data/search_brand.txt`로 저장
5. `python run_all.py` 다시 실행 → 결과 엑셀에 **무신사_검색노출** 시트가 생김

판정 기준: 검색창에 **"어반드레스 + 상품명"**(컬러명·컬러 묶음 표시를 뗀 이름)을 넣었을 때, 결과에 **그 상품번호가 브랜드 "어반드레스"로** 나오면 `검색됨`. 무신사 검색 화면이 쓰는 것과 같은 검색 API를 호출하고, 최대 300개 결과까지 확인합니다.

## 결과 엑셀 읽는 법

### 무신사_옵션재고점검 (메인)

모든 시트의 **1행에 "왜 만들었나 / 읽는 법"** 설명이 있고, 2행이 헤더, 3행부터 데이터입니다.

| 시트 | 왜 만들었나 |
|---|---|
| **요약** | 파일 전체 결과를 숫자로 모음. 다른 시트를 수식으로 집계 |
| **상품별_한눈에보기** | 옵션별 결과는 한 상품이 여러 줄이라 확인이 어려워서, 무신사 상품 1개 = 1줄로 묶고 **조치가 필요한 상품만** 남김. 품절 옵션은 `BLACK: S(12)·M(5) \| GREY: L(3)`처럼 컬러별로 묶고 괄호 안은 셀메이트 재고. 작업은 이 시트부터 |
| **무신사_검색노출** | 정상 등록돼 있어도 검색 시 우리 브랜드 상품으로 안 나오는 경우를 찾기 위해 "어반드레스 + 상품명" 검색 결과 확인 (search_brand.txt가 있을 때만) |
| **옵션별_점검** | 셀메이트 재고 있는데 무신사 옵션이 품절(재고 입력 실수)이거나, 컬러 묶음 상품에서 일부 옵션만 품절인 경우를 찾기 위한 **옵션 1:1 대조 상세**. 맨 끝 열에 매칭 근거 |
| **무신사에_옵션없음** | 셀메이트엔 재고 있는 옵션인데 무신사 상품에 그 옵션 자체가 없어 고객이 고를 수 없는 경우 (품절이 아니라 누락) |
| **상품명_대조** | 스타일넘버만으로 놓치는 경우를 막기 위해 스타일넘버·상품명(컬러·COL 제외)으로 교차 확인. **정상 일치 상품은 기록하지 않음.** `확인:`으로 시작하면 스타일넘버 오입력 의심 |

#### 옵션 판정

| 판정 | 의미 | 조치 |
|---|---|---|
| 무신사 품절(셀메이트 재고 있음) | 셀메이트 재고 > 0, 무신사 판매가능 0 | 무신사 재고 입력 확인 (가장 우선) |
| 판매 제한(재고 입력됐는데 판매가능 0) | 무신사 브랜드배송 재고는 있는데 총합 판매가능 0 | 허용판매수량 등 판매 제한 설정 확인 |
| 품절(다른 상품번호에서는 판매중) | 같은 셀메이트 옵션이 다른 무신사 상품에서는 판매중 | 중복 등록 상품 정리 |
| 초과판매 위험(셀메이트 재고 없음) | 셀메이트 0인데 무신사 브랜드배송 재고 남음 | 재고를 일부러 넉넉히 잡은 경우가 있어 한눈에보기에서는 제외 |
| 확인필요(옵션 매칭 안 됨) | 컬러 없이 남은 잔여 옵션, (기모)·(LONG) 같은 변형 옵션, 같은 상품 안 중복 옵션, 셀메이트에 없는 컬러·사이즈 | 맨 끝 "옵션 매칭" 열 사유 확인 |
| 정상 판매 / 정상 판매(무신사 풀필먼트 출고) | 판매중. 브랜드배송 0이어도 **MFS 재고가 있으면 셀메이트 재고와 무관하게 정상** | — |
| 정상 품절(양쪽 재고 없음) | 셀메이트·무신사 모두 0 | — |
| 대조 제외(세트상품) | `[SET]`, `[패키지]`, `[2PACK]` 상품 | 셀메이트엔 단품으로만 있어 대조 안 함 |

### 무신사_어반드레스_등록점검

| 시트 | 왜 만들었나 |
|---|---|
| **요약** | 무신사 등록 현황을 숫자로 모음 |
| **무신사_어반드레스_점검** | 셀메이트 우리 브랜드 상품(컬러 단위)이 무신사에 등록·판매중인지 확인. `무신사 판정` 열: **등록·미노출**(품절·판매중지 등) → **미등록**(매칭 없음·삭제) → **등록·노출**(판매중) 순서 |
| **무신사에만_있는상품** | 셀메이트엔 없는데 무신사에만 있는 상품 확인 (대부분 `[SET]`·`[패키지]` 상품) |

## 매칭 방식

1. **스타일넘버**: 셀메이트 상품코드 전체 또는 앞 8자리 기본코드(예: `AD63PT09`)와 무신사 스타일넘버 비교. 무신사가 컬러 묶음 상품(기본코드)이면 모든 컬러를 포함한 것으로 봄.
2. **상품명**: 양쪽 상품명에서 아래를 떼고 비교
   - 머리말 `[SET]` `[패키지]`
   - 컬러 묶음 표시 `_3COL` `- 4COL` `5 COLOR` `_2Colors` `(N)`
   - 끝에 붙은 컬러명 `BLACK` `LIGHT BLUE` `PIGMENT GREY` `블랙` `다크베이지` `-크림` …
   - 컬러 사전은 한/영 기본 목록 + 데이터에서 상품명 끝에 자주 나오는 대문자 단어를 자동 수집 (`HOODIE`, `PANTS` 등 옷 종류 단어는 제외)
   - 오타·띄어쓰기 차이는 유사도 0.86 이상이면 `유사 상품명(확인필요)`
3. **옵션**: 무신사 옵션 `컬러^사이즈`(또는 `컬러 사이즈`)를 셀메이트 상품 컬러(상품명 끝 또는 옵션명)와 옵션명 사이즈에 맞춤. 한/영 컬러(`블랙`=`BLACK`), 사이즈 표기(`S(1)`=`1(S)`, `F`=`FREE`) 차이 반영.
4. **스타일넘버 오입력 보정**: 스타일넘버가 가리키는 상품과 상품명이 같은 상품이 다르면, 상품명 기준 셀메이트 상품으로 옵션을 다시 연결 (`옵션 매칭` 열에 "재연결" 표시). 한글/영문이 달라 자동으로 못 찾는 상품은 `config.py`의 `MANUAL_LINKS`에 직접 적습니다.

## 설정 (`config.py`)

| 항목 | 설명 |
|---|---|
| `BRAND_KR` | 브랜드명 (검색어·시트 제목에 사용) |
| `TARGET_CODE_PATTERN` | 점검 대상 셀메이트 상품코드 정규식 |
| `EXCLUDE_CODE_PATTERN` | 제외할 다른 브랜드 코드 정규식 |
| `MANUAL_LINKS` | `{무신사 상품번호: [셀메이트 상품코드…]}` 사람이 확인한 연결 |
| `MANUAL_SHORT_LINKS` | 긴팔 상품 안에 섞인 `(short)` 옵션을 반팔 상품에 연결 |
| `LISTING_NOTES`, `SELLMATE_NOTES` | 결과 시트 메모 |

무신사에서 스타일넘버를 고친 뒤에는 해당 `MANUAL_LINKS` 항목을 지워도 됩니다.

## 주의사항

- 셀메이트 재고는 파일을 받은 시점 기준입니다. 무신사 파일과 받은 시각이 다르면 그 사이 주문만큼 차이가 날 수 있습니다.
- 재고 관리(v2) 복사본에 없는 판매중 상품은 옵션 점검이 안 됩니다. 복사할 때 상품상태·출력수 필터를 확인하고, 5000건이 넘으면 다음 페이지도 이어 붙이세요.
- 검색 스크립트는 무신사 웹 화면이 쓰는 비공개 API를 그대로 호출합니다. 무신사 사이트가 바뀌면 동작하지 않을 수 있습니다.
- 검색 순위는 시점마다 달라집니다. 참고용으로 보세요.

버전별 변경 내용은 [CHANGELOG.md](CHANGELOG.md)에 있습니다.
