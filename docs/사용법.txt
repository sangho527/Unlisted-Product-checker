판매채널 상품 점검 - 무신사 · 29CM (SalesChannelChecker.exe)
=====================================================

화면 맨 위 [판매채널]에서 무신사 또는 29CM를 고릅니다. 29CM 사용법은 맨 아래 [29CM] 부분을 보세요.

무신사 판매중 상품 중
 · 셀메이트에 재고가 있는데 무신사 옵션이 품절(판매 제한)이라 살 수 없는 옵션
 · 고객이 상품명으로 검색했을 때 안 나오는 상품
을 찾습니다.


[준비할 파일 ①] 재고 관리(v2) 복사본
1. 무신사 파트너센터 → 상품/재고 → 재고 관리(v2)
2. 상품상태 "판매중", 출력수 "5000" → 조회
3. 표를 처음부터 끝까지 드래그해서 복사(Ctrl+C)
4. 엑셀 새 파일에 붙여넣기(Ctrl+V) → 저장
   - 머리글(매장명, 업체 ...) 행은 없어도 됩니다. 필요한 열만 자동으로 골라 씁니다.
   - 5000건이 넘으면 2페이지도 이어서 붙여넣으세요.

[준비할 파일 ②] 셀메이트 재고목록
셀메이트 → 재고목록 → 엑셀(CSV) 다운로드한 파일(stk_stockList_*.csv) 그대로.
(품절)·(이월) 표시와 관계없이 현재재고 수량이 있으면 재고 있음으로 봅니다.
무신사 복사본과 같은 날 받은 파일을 쓰세요.


[사용법]
1. SalesChannelChecker.exe 실행
   (처음 실행 시 Windows 보호 화면이 뜨면 "추가 정보" → "실행")
2. [찾아보기]로 재고 관리(v2) 복사본, 셀메이트 재고목록 선택
3. [▶ 점검 시작]
   ① "무신사_옵션재고점검_날짜.xlsx"가 먼저 만들어집니다 (1분 정도)
   ② 크롬 창이 하나 새로 열리고, 무신사 검색창에 "어반드레스 + 상품명"을 하나씩 입력해 검색합니다.
      - 판매중 상품 전체를 검색합니다 (상품 1,000개 기준 40~60분).
      - 그 크롬 창은 건드리지 마세요 (최소화는 괜찮습니다). 평소 쓰는 크롬과는 따로 열립니다.
      - 검색 결과 화면에 그 상품이 안 보이면 화면을 캡처해 "미노출_캡처" 폴더에 저장합니다.
4. 끝나면 결과 폴더에서 확인
   - 무신사_검색노출점검_날짜.xlsx → "검색_미노출" 시트 ("캡처 보기"를 누르면 검색 화면 캡처가 열림)
   - 무신사_옵션재고점검_날짜.xlsx → "상품별_한눈에보기" 시트
   - 미노출_캡처 폴더 → 상품번호_상품명.png

[중간에 멈추고 싶을 때]
- [■ 중지]를 누르면 지금까지 검색한 결과로 엑셀을 만듭니다 (나머지는 "미확인").
- [검색만 이어서 하기]를 누르면 멈춘 곳 다음부터 검색합니다.
- 다른 날 새 파일로 점검하려면 [▶ 점검 시작]부터 다시 하세요 (이전 검색 기록·캡처는 지워집니다).

[자동 검색이 안 될 때 (예비)]
"콘솔 스크립트 복사 + 무신사 열기" → 무신사 페이지에서 F12 → Console 탭 → Ctrl+V → Enter
→ 콘솔에 "완료"가 나오면 "콘솔 결과 붙여넣기" (그 사이 다른 걸 복사하거나 화면 캡처하지 마세요)


[결과 보는 법 - 무신사_옵션재고점검]
- 상품별_한눈에보기 : 조치가 필요한 상품만 1상품 1줄 (여기부터 보세요)
  ① 셀메이트 재고 있는 옵션 품절 → 무신사 재고 입력 확인
  ② 품절 옵션이 다른 옵션명·상품번호로 판매중 → 우선순위 낮음(중복 옵션·상품 정리)
  ③ 확인필요 옵션 있음 → 옵션 매칭이 안 된 옵션
- 옵션별_점검 : 옵션 1:1 대조 전체
- 무신사에_옵션없음 : 셀메이트 재고가 있는데 무신사에 그 옵션 자체가 없음
- 상품명_대조 : 스타일넘버 오입력 의심 상품
- 브랜드배송 0 + 무신사배송(MFS) 재고가 있으면 셀메이트 재고와 상관없이 정상입니다.

[결과 보는 법 - 무신사_검색노출점검]
- 검색_미노출 : 판매중인데 검색 결과 화면에 안 나오는 상품만 (여기부터 보세요, "캡처 보기"로 검색 화면 확인)
- 전체_검색결과 : 판매중 상품 전체 결과
- 요약 : 상품 수, 원인별 수
- 각 시트 맨 위에 "왜 만들었나 / 읽는 법"이 적혀 있습니다.
- 비고에 원인을 적었습니다.
  · 상품명에 UNISEX·유니섹스가 들어간 상품은, 검색해서 안 나오면 그 단어를 빼고 한 번 더 검색합니다.
    그래서 나오면 "검색됨 (UNISEX·유니섹스 빼고 재검색)"으로 표시 → 상품명에서 UNISEX·유니섹스 제외 검토.
  · 전 옵션 품절(판매가능 재고 0) 상품은 검색에서 빠졌을 수 있습니다.


[검색 방법]
- 고객처럼 무신사 상단 [검색] 버튼 → 검색창에 입력 → Enter
- 검색어: "브랜드명 + 상품명" (상품명 끝의 컬러명, _3COL / 7 COLOR 같은 표기는 뺌)
- 안 나오면 UNISEX·유니섹스를 빼고 한 번 더 검색 (무신사·29CM 공통, 설정의 SEARCH_DROP_WORDS)
- 검색 결과 화면을 내려가며 상품 카드 최대 60개까지 보고, 그 상품이 우리 브랜드로 나오면 "검색됨"
  ('함께 본 29CM 상품' 같은 추천 영역은 제외)
- 비로그인 웹 검색 기준입니다 (이 프로그램 전용 크롬 프로필). 앱은 확인하지 않습니다.


[설정]
[설정(브랜드명)] 버튼 → settings.json 이 열립니다.
- BRAND_KR: 무신사·29CM에 표시되는 브랜드명 (기본: 어반드레스)
- EXCLUDE_CODE_PATTERN: 점검에서 뺄 스타일넘버 규칙 (기본: ^(ZD|VV) → ZD·VV로 시작하는 상품 제외)
- SEARCH_DROP_WORDS: 검색해서 안 나오면 빼고 다시 검색할 단어 (기본: ["UNISEX", "유니섹스"])
저장한 뒤 [▶ 점검 시작]부터 다시 실행하면 반영됩니다.


=====================================================
[29CM]
=====================================================
29CM 판매중 상품 중
 · 셀메이트에 재고가 있는데 29CM 옵션이 일시품절·판매중지라 살 수 없는 옵션
 · 고객이 29CM에서 "브랜드명 + 상품명"으로 검색했을 때 안 나오는 상품
을 찾습니다.

[준비할 파일 ①] 29CM 옵션재고 일괄변경 파일 (여러 개)
1. 29Connect(29CM 파트너) → 옵션/재고 관리 → 판매상태 "판매중"으로 조회
2. 페이지마다 엑셀 다운로드 → "29CM_옵션재고_일괄변경(파트너)_페이지…xlsx" 파일이 여러 개 생김
3. 프로그램 [찾아보기]에서 그 파일들을 Ctrl(또는 Shift)로 한꺼번에 선택
   - 파일 순서는 상관없고, 두 파일에 같은 옵션이 들어 있어도 한 번만 셉니다.
   - 파일을 받은 그대로 쓰면 됩니다 (위쪽 안내문 줄은 알아서 건너뜁니다).

[준비할 파일 ②] 셀메이트 재고목록 — 무신사와 같은 파일(stk_stockList_*.csv)

[사용법]
1. [판매채널]에서 29CM 선택
2. 1번에 29CM 파일들, 2번에 셀메이트 재고목록 선택 → [▶ 점검 시작]
   ① "29CM_옵션재고점검_날짜.xlsx"가 먼저 만들어집니다 (1분 정도)
   ② 크롬 창이 새로 열리고, 29CM 검색창에 "어반드레스 + 상품명"을 하나씩 입력해 검색합니다.
      검색 결과 화면에 그 상품이 안 보이면 화면을 캡처해 "29CM_미노출_캡처" 폴더에 저장합니다.
3. [■ 중지] / [검색만 이어서 하기]는 무신사와 같습니다 (판매채널을 29CM로 둔 채 누르세요).

[상품명 매칭 방법]
29CM 파일에는 셀메이트 상품코드가 없어서 상품명으로 셀메이트 상품을 찾습니다.
- 상품명 끝 컬러명, "- 3COL" "_3Colors" "7 COLOR" 같은 컬러 묶음 표기를 떼고 비교
- 셀메이트 상품명 = 29CM 상품명 + 컬러인 경우, 29CM 상품명 단어가 모두 들어 있는 경우, 비슷한 이름
- 한글 상품명 ↔ 영문 상품명 (예: 테사 세미 와이드 팬츠 = Tessa Semi Wide Pants) — 의류 용어 사전과 발음 비교
- [SET] A + B 세트 상품은 구성품을 각각 찾고, 셀메이트 재고는 구성품 중 적은 쪽으로 봄
- 옵션은 [색상]/[사이즈]/[컬러] 꼬리표를 떼고 컬러·사이즈로 맞춤 (블랙 = BLACK). (기모)·(쭈리) 구분이 다르면 다른 옵션.
- 정확히 같은 이름이 아닌 매칭은 "상품매칭_확인필요" 시트에 모아 두니 한 번 확인하세요.

[결과 보는 법 - 29CM_옵션재고점검]
- 상품별_한눈에보기 : 조치가 필요한 상품만 1상품 1줄 (여기부터 보세요)
  ① 29CM 일시품절인데 셀메이트 재고 있음  ② 29CM 판매중지인데 셀메이트 재고 있음  ③ 셀메이트에서 같은 옵션을 못 찾음
  검색까지 끝나면 "29CM 검색" 열에 검색 결과가 붙습니다.
- 옵션별_대조 : 29CM 옵션 전체 ↔ 셀메이트 옵션 (29CM 쪽은 상품명·브랜드·옵션명·옵션 판매상태·재고 수량)
- 29CM에_옵션없음 : 셀메이트 재고가 있는데 29CM에 그 컬러·사이즈가 없음
- 상품매칭_확인필요 : 상품명이 정확히 같지 않아 비슷한 이름·한글↔영문으로 연결한 상품

[결과 보는 법 - 29CM_검색노출점검]
- 검색_미노출 : 판매중인데 검색 결과 화면에 안 나오는 상품 ("캡처 보기" / "검색 열기")
- 전체_검색결과 : 판매중 상품 전체. "검색됨 (품절 표시)"는 검색은 되지만 카드에 품절로 보이는 상품
  "검색됨 (UNISEX·유니섹스 빼고 재검색)"은 그 단어를 빼고 다시 검색해야 나오는 상품 (재검색어 열)
- 확인 범위: 비로그인 29CM 웹 검색, 추천순 첫 페이지(최대 50개). 앱·카테고리·브랜드관은 확인하지 않습니다.
