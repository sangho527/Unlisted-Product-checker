무신사 미등록·옵션 품절 점검 (MusinsaChecker.exe)
=================================================

[준비할 파일 3개]
1. 셀메이트 재고목록 (.csv)
   셀메이트 → 재고 목록 → 엑셀 다운로드 (stk_stockList_날짜.csv)
2. 무신사 상품정보조회 – 판매중 (.xlsx)
   무신사 파트너센터 → 상품정보조회 → 상품상태 "판매중" → 엑셀 다운로드
3. 무신사 재고관리(v2) 옵션 목록 (.xlsx)
   재고 관리(v2) → 상품상태 판매중, 출력수 5000 → 표 전체를 드래그해서 복사(Ctrl+C)
   → 엑셀 새 파일에 붙여넣기(Ctrl+V) → 저장
   (5000건이 넘으면 2페이지도 이어서 붙여넣기)
(선택) 무신사 상품정보조회 – 전체 (.xlsx)
   상품상태 "전체" → 엑셀 다운로드. 넣으면 미등록·판매중지 상품을 찾는 등록점검 엑셀도 만듭니다.
   판매중 상품의 옵션 품절·검색 노출만 볼 때는 필요 없습니다.

[사용법]
1. MusinsaChecker.exe 실행 (처음 실행 시 Windows 보호 화면이 뜨면 "추가 정보" → "실행")
2. 파일 3개를 [찾아보기]로 고르기 (전체 파일은 선택)
3. [점검 시작] → 1~2분 뒤 결과 폴더에 엑셀이 생깁니다
   - 무신사_옵션재고점검_날짜.xlsx   ← 메인. "상품별_한눈에보기" 시트부터 보세요
   - 무신사_어반드레스_등록점검_날짜.xlsx  (전체 파일을 넣었을 때만)
   각 시트 맨 위에 "왜 만들었나 / 읽는 법"이 적혀 있습니다.

[선택] 무신사 검색 노출 확인
1. 점검이 끝난 뒤 [① 검색 스크립트 복사 + 무신사 열기]
2. 열린 무신사 페이지(크롬)에서 F12 → Console 탭 → Ctrl+V → Enter
   (처음이면 "allow pasting" 이라고 입력하고 Enter 한 뒤 다시 Ctrl+V)
3. 2~3분 뒤 콘솔에 "완료" 가 나오면 [② 복사된 검색 결과 붙여넣기 → 엑셀 반영]
   → 옵션재고점검 엑셀에 "무신사_검색노출" 시트가 생깁니다.

[설정]
[설정(브랜드·수동 연결)] 버튼 → settings.json 이 열립니다.
- BRAND_KR: 브랜드명 (검색어에 사용)
- TARGET_CODE_PATTERN: 점검할 셀메이트 상품코드 규칙 (기본: AD·AV로 시작)
- EXCLUDE_CODE_PATTERN: 제외할 다른 브랜드 코드 (기본: ZD·VV)
- MANUAL_LINKS: 스타일넘버가 잘못 입력된 무신사 상품 → 셀메이트 상품코드 수동 연결
저장 후 다시 [점검 시작]을 누르면 반영됩니다.

[주의]
- 결과 엑셀과 입력 파일에는 재고·원가 정보가 들어 있으니 외부에 공유하지 마세요.
- 셀메이트의 (품절)·(이월) 표시와 상관없이 재고 수량이 있으면 재고 있음으로 판단합니다.
- 무신사 웹 검색은 검색어에 '유니섹스'가 들어가면 결과 화면이 비어 보이는 현상이 있습니다.
