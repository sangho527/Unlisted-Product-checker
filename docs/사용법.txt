무신사 판매중 상품 점검 (MusinsaChecker.exe)
============================================

무신사 판매중 상품 중
 · 셀메이트에 재고가 있는데 무신사 옵션이 품절(판매 제한)이라 살 수 없는 옵션
 · 고객이 상품명으로 검색했을 때 안 나오는 상품
을 찾습니다.


[준비할 파일 ①] 재고 관리(v2) 복사본
1. 무신사 파트너센터 → 상품/재고 → 재고 관리(v2)
2. 상품상태 "판매중", 출력수 "5000" → 조회
3. 표를 처음부터 끝까지 드래그해서 복사(Ctrl+C)
4. 엑셀 새 파일에 붙여넣기(Ctrl+V) → 저장
   - 머리글(매장명, 업체 ...) 행은 없어도 됩니다. 필요한 열만 자동으로 골라 씁니다.
   - 5000건이 넘으면 2페이지도 이어서 붙여넣으세요.

[준비할 파일 ②] 셀메이트 재고목록
셀메이트 → 재고목록 → 엑셀(CSV) 다운로드한 파일(stk_stockList_*.csv) 그대로.
(품절)·(이월) 표시와 관계없이 현재재고 수량이 있으면 재고 있음으로 봅니다.
무신사 복사본과 같은 날 받은 파일을 쓰세요.


[사용법]
1. MusinsaChecker.exe 실행
   (처음 실행 시 Windows 보호 화면이 뜨면 "추가 정보" → "실행")
2. [찾아보기]로 재고 관리(v2) 복사본, 셀메이트 재고목록 선택
3. [▶ 점검 시작]
   ① "무신사_옵션재고점검_날짜.xlsx"가 먼저 만들어집니다 (1분 정도)
   ② 크롬 창이 하나 새로 열리고, 무신사 검색창에 "어반드레스 + 상품명"을 하나씩 입력해 검색합니다.
      - 판매중 상품 전체를 검색합니다 (상품 1,000개 기준 40~60분).
      - 그 크롬 창은 건드리지 마세요 (최소화는 괜찮습니다). 평소 쓰는 크롬과는 따로 열립니다.
      - 검색 결과 화면에 그 상품이 안 보이면 화면을 캡처해 "미노출_캡처" 폴더에 저장합니다.
4. 끝나면 결과 폴더에서 확인
   - 무신사_검색노출점검_날짜.xlsx → "검색_미노출" 시트 ("캡처 보기"를 누르면 검색 화면 캡처가 열림)
   - 무신사_옵션재고점검_날짜.xlsx → "상품별_한눈에보기" 시트
   - 미노출_캡처 폴더 → 상품번호_상품명.png

[중간에 멈추고 싶을 때]
- [■ 중지]를 누르면 지금까지 검색한 결과로 엑셀을 만듭니다 (나머지는 "미확인").
- [검색만 이어서 하기]를 누르면 멈춘 곳 다음부터 검색합니다.
- 다른 날 새 파일로 점검하려면 [▶ 점검 시작]부터 다시 하세요 (이전 검색 기록·캡처는 지워집니다).

[자동 검색이 안 될 때 (예비)]
"콘솔 스크립트 복사 + 무신사 열기" → 무신사 페이지에서 F12 → Console 탭 → Ctrl+V → Enter
→ 콘솔에 "완료"가 나오면 "콘솔 결과 붙여넣기" (그 사이 다른 걸 복사하거나 화면 캡처하지 마세요)


[결과 보는 법 - 무신사_옵션재고점검]
- 상품별_한눈에보기 : 조치가 필요한 상품만 1상품 1줄 (여기부터 보세요)
  ① 셀메이트 재고 있는 옵션 품절 → 무신사 재고 입력 확인
  ② 품절 옵션이 다른 옵션명·상품번호로 판매중 → 우선순위 낮음(중복 옵션·상품 정리)
  ③ 확인필요 옵션 있음 → 옵션 매칭이 안 된 옵션
- 옵션별_점검 : 옵션 1:1 대조 전체
- 무신사에_옵션없음 : 셀메이트 재고가 있는데 무신사에 그 옵션 자체가 없음
- 상품명_대조 : 스타일넘버 오입력 의심 상품
- 브랜드배송 0 + 무신사배송(MFS) 재고가 있으면 셀메이트 재고와 상관없이 정상입니다.

[결과 보는 법 - 무신사_검색노출점검]
- 검색_미노출 : 판매중인데 검색 결과 화면에 안 나오는 상품만 (여기부터 보세요, "캡처 보기"로 검색 화면 확인)
- 전체_검색결과 : 판매중 상품 전체 결과
- 요약 : 상품 수, 원인별 수
- 각 시트 맨 위에 "왜 만들었나 / 읽는 법"이 적혀 있습니다.
- 비고에 원인을 적었습니다.
  · '유니섹스'가 들어간 검색어는 무신사 웹 검색 화면이 비어 보입니다(사이트 전체 현상).
    상품명에서 '유니섹스'를 빼면 노출됩니다.
  · 전 옵션 품절(판매가능 재고 0) 상품은 검색에서 빠졌을 수 있습니다.


[검색 방법]
- 고객처럼 무신사 상단 [검색] 버튼 → 검색창에 입력 → Enter
- 검색어: "브랜드명 + 상품명" (상품명 끝의 컬러명, _3COL / 7 COLOR 같은 표기는 뺌)
- 검색 결과 화면을 내려가며 상품 카드 최대 60개까지 보고, 그 상품이 우리 브랜드로 나오면 "검색됨"
  ('함께 본 29CM 상품' 같은 추천 영역은 제외)
- 비로그인 웹 검색 기준입니다 (이 프로그램 전용 크롬 프로필). 앱은 확인하지 않습니다.


[설정]
[설정(브랜드명)] 버튼 → settings.json 이 열립니다.
- BRAND_KR: 무신사에 표시되는 브랜드명 (기본: 어반드레스)
- EXCLUDE_CODE_PATTERN: 점검에서 뺄 스타일넘버 규칙 (기본: ^(ZD|VV) → ZD·VV로 시작하는 상품 제외)
저장한 뒤 [▶ 점검 시작]부터 다시 실행하면 반영됩니다.
