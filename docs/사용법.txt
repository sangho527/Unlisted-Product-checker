무신사 검색 노출 점검 (MusinsaChecker.exe)
==========================================

무신사에 판매중인데 고객이 상품명으로 검색했을 때 안 나오는 상품을 찾습니다.


[준비할 파일 1개] 재고 관리(v2) 복사본
1. 무신사 파트너센터 → 상품/재고 → 재고 관리(v2)
2. 상품상태 "판매중", 출력수 "5000" → 조회
3. 표를 처음부터 끝까지 드래그해서 복사(Ctrl+C)
4. 엑셀 새 파일에 붙여넣기(Ctrl+V) → 저장
   - 머리글(매장명, 업체 ...) 행은 없어도 됩니다. 필요한 열만 자동으로 골라 씁니다.
   - 5000건이 넘으면 2페이지도 이어서 붙여넣으세요.


[사용법]
1. MusinsaChecker.exe 실행
   (처음 실행 시 Windows 보호 화면이 뜨면 "추가 정보" → "실행")
2. [찾아보기]로 재고 관리(v2) 복사본 선택
3. ① 상품 목록 만들기
4. ② 검색 스크립트 복사 + 무신사 열기
   → 열린 무신사 페이지(크롬)에서 F12 → Console 탭 → Ctrl+V → Enter
   (처음이면 "allow pasting" 이라고 입력하고 Enter 한 뒤 다시 Ctrl+V)
   → 상품 1,000개 기준 약 10분. 그동안 그 탭을 닫지 마세요.
   → 콘솔에 "완료"가 나오면 결과가 자동으로 복사됩니다.
5. ③ 검색 결과 붙여넣기 → 엑셀 완성
6. 결과 폴더의 "무신사_검색노출점검_날짜.xlsx" → "검색_미노출" 시트 확인


[결과 보는 법]
- 검색_미노출 : 판매중인데 검색 결과 화면에 안 나오는 상품만 (여기부터 보세요)
- 전체_검색결과 : 판매중 상품 전체 결과
- 요약 : 상품 수, 원인별 수
- 각 시트 맨 위에 "왜 만들었나 / 읽는 법"이 적혀 있습니다.
- 비고에 원인을 적었습니다.
  · '유니섹스'가 들어간 검색어는 무신사 웹 검색 화면이 비어 보입니다(사이트 전체 현상).
    상품명에서 '유니섹스'를 빼면 노출됩니다.
  · 전 옵션 품절(판매가능 재고 0) 상품은 검색에서 빠졌을 수 있습니다.


[검색 방법]
- 검색어: "브랜드명 + 상품명" (상품명 끝의 컬러명, _3COL / 7 COLOR 같은 표기는 뺌)
- 실제 검색 결과 화면(첫 페이지)에 그 상품이 우리 브랜드로 나오면 "검색됨"
- 비로그인 웹 검색 기준입니다. 앱은 확인하지 않습니다.


[설정]
[설정(브랜드명)] 버튼 → settings.json 이 열립니다.
- BRAND_KR: 무신사에 표시되는 브랜드명 (기본: 어반드레스)
- EXCLUDE_CODE_PATTERN: 점검에서 뺄 스타일넘버 규칙 (기본: ^(ZD|VV) → ZD·VV로 시작하는 상품 제외)
저장한 뒤 ① 상품 목록 만들기부터 다시 실행하면 반영됩니다.
